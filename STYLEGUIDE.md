# 12.1 Core Principles (Expanded for 5.8 UNIFIED)

### NEW (5.8)
- all module interactions and execution pipelines must be managed centrally by `sirius_orchestrator.py`  
- sensitive operations and autonomous confirmations must prompt user approval via `PanelAPI` (`[ÁNO/NIE]`)  
- execution timing and security tracking must be governed by `TimeCore` and `Guard`  
- all OS‑level actions must be **predictively validated** using System Intelligence Layer 5.8  
- System Agent 5 is the **only validator** of OS‑level actions  
- identity‑aware logic must be **constant‑time and unified across PC + Mobile**  
- no workflow may run in a **risky or degraded OS state**  
- all modules must support **deterministic fallback logic 3.2**  
- reasoning must be **bounded, cached, KG‑aware, pack‑aware, repair‑aware, autonomy‑aware, and COLNIK‑validated**  
- UI Automation must use **fuzzy matching 5.8**  
- ENVOY fetch must follow **ASK → FETCH → QUARANTINE → VALIDATE → DELIVER**  
- no module may bypass KG‑Reasoning when semantic inference is required  
- KG_EXPLAIN + KG_EXPLAIN_DEEP must be used for explainability in reasoning, workflows, and OS‑level decisions  
- Self‑Repair Layer 5.8 must be consulted when degraded mode is detected  
- Unified KG 5.8 must validate semantic consistency before inference (`autosave_kg.json`)  
- Workflow Engine 5.8 must use **KG_EXPLAIN_DEEP routing**  
- **COLNIK‑6.x (Standard & IPC Mode) must validate all critical decisions (KG, workflows, reasoning, ENVOY, OS actions)**  
- **AUTONOMY‑6.x (Control & Triage Mode) must validate all autonomous proposals before execution**
